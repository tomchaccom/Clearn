Obsidian 연동 (선택)

학습 기록을 Obsidian 노트로 자동 내보낼 수 있어요.

Obsidian이 설치되어 있나요?

Obsidian 설치 방법
  1. 아래 버튼으로 Obsidian을 다운로드·설치하세요
  2. 앱 실행 후 "새 보관함 만들기" 선택
  3. 저장할 폴더 위치를 기억해두세요
  4. 설치 후 아래 "보관함 선택"을 눌러주세요

보관함 폴더를 선택하세요

보관함 = Obsidian이 노트를 저장하는 폴더예요.
Obsidian 앱 왼쪽 하단 금고 아이콘에서 경로를 확인할 수 있어요.

준비 완료 ✓

탐구 탭에서 궁금한 것 하나를 골라
내 추측을 먼저 적어보세요.

막히면 힌트 사다리(L0~L3)를 활용하고,
대화가 쌓이면 인출 카드로 만들어 복습하세요.
